SKILLS · ROUTING · GATES · QA

skills_UIUX

Đóng gói kiến thức UI/UX thành một hệ thống để AI coding agent biết cần dùng skill nào, ở phase nào và evidence nào đủ để đi tiếp.

01 / PROBLEM

Model mạnh vẫn có thể cho output không ổn định

Website work cần nhiều loại quyết định: project truth, research, IA, visual direction, implementation, responsive/accessibility, QA và release. Nếu toàn bộ phụ thuộc vào một prompt lớn hoặc model prior, context dễ nhiễu và gate chất lượng khó lặp lại.

02 / ARCHITECTURE

Progressive disclosure thay cho load mọi thứ

Skill Library mode

Agent host chỉ discover metadata trước, sau đó load SKILL.md và resources khi task thật sự cần.

Agent OS mode

Development Manager quyết định flow; flow quyết định agent/skill; provider chỉ reasoning trong active stage.

Evidence gates

No evidence → no validated claim; build/CI không được thay cho rendered visual QA.

Context budget

Chọn smallest applicable skill graph để giảm prompt noise và giữ project truth ưu tiên cao hơn external intelligence.

03 / RELIABILITY

Hard truth rules biến QA thành contract

V5.4 thêm elementary visual sanity gate cho contrast, shared surface/foreground, CTA state, computed styles và focal crop. Failure có tính khái quát phải được promote thành regression rule thay vì chỉ sửa riêng một project.

CURRENT BOUNDARY

Repo vừa là portable skill library vừa có optional Agent OS. Những capability như rendered QA chỉ được claim khi runtime/tool evidence thực sự tồn tại ở phase tương ứng.
