UI Feedback Tool

A small tool for turning “this part feels wrong” into precise, element-level feedback without leaving the page being reviewed.

01 / PROBLEM

Visual feedback loses precision when it leaves the interface

Design iteration often turns into screenshots, chat messages and vague instructions that separate the feedback from the element being discussed. The tool keeps the reviewer on the page: select an element, add a note or change text/CSS/image state, preserve the session locally and export a structured Markdown handoff.

InputElement-level selectionFeedback starts from the exact UI object.
EditText, CSS and imagePreview changes in context before saving.
PersistenceProject-scoped localStorageRefresh without losing the working session.
OutputAI-ready MarkdownExport selector, current state and intended change.
02 / WORKFLOW

The interaction model follows the way visual review actually happens

01 / ActivateOpen the tool

A deliberate Q → W → E shortcut keeps the overlay out of normal browsing.

02 / TargetSelect the element

The tool resolves the exact DOM target instead of relying on screenshot coordinates.

03 / AdjustPreview in context

Edit copy, CSS or imagery and keep undo/cancel paths available.

04 / HandoffExport structured feedback

Markdown captures page, selector, state and requested result for implementation or AI-assisted work.

03 / SYSTEM REALITY

A lightweight design-preview tool, not production end-user UI

The source is modular and builds to a single ESM artifact that can be embedded in opted-in projects. The canonical repository also supports downstream sync workflows, while each project keeps its own storage key and configuration.

INTENDED ENVIRONMENT

This is a personal design/review tool for preview or staging contexts. It should not be enabled by default for production visitors. Uploaded image data is constrained to reduce localStorage pressure, and the runtime does not silently replace project code from an external host.
