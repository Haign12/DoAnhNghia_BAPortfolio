DESIGNOPS · VISUAL FEEDBACK · AI WORKFLOW

UI Feedback Tool

Rút ngắn khoảng cách giữa “mình thấy UI này cần sửa” và một task đủ cụ thể để designer/developer/AI hiểu ngay.

01 / PROBLEM

Feedback UI thường mất ngữ cảnh khi rời khỏi màn hình

Screenshot, chat và mô tả thủ công thường làm mất selector, trạng thái hiện tại, CSS thay đổi hoặc vị trí ảnh. Tool đưa feedback vào đúng phần tử trên trang preview và lưu context ngay tại nguồn.

02 / FLOW

Một loop cá nhân ngắn và có thể đảo ngược

Select

Bật tool bằng Q→W→E, chọn Comment/Edit/CSS/Image rồi click đúng element.

Edit in context

Text, CSS và image changes preview trực tiếp; cancel/toggle off có thể phục hồi trạng thái chưa lưu.

Persist

Feedback được nhóm theo page và lưu bằng localStorage theo storageKey riêng.

Export

Markdown xuất ra chứa URL, selector, trạng thái hiện tại, kết quả mong muốn và phần CSS/image thay đổi.

03 / SYSTEM

Tool nhỏ nhưng có architecture rõ

Source tách core state/persistence, feature editors, UI shell, stylesheet và generated ESM bundle. Tool không phụ thuộc React/Vue/Tailwind và có workflow sync opt-in sang các project khác.

USAGE BOUNDARY

Đây là công cụ cho design/preview/staging workflow cá nhân; repo ghi rõ không nên bật mặc định trong production cho end user.
