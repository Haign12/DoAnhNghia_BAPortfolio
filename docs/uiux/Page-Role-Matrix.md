# Page Role / Composition Matrix

## Composition family definitions

- **A — Editorial Proof Index:** Home/orientation.
- **B — Artifact-Led Case:** LuxRoom, Atelier, StudioOS with project-specific media sequencing.
- **C — Change-Thesis Case:** VAS Education redesign.
- **D — System-Model Case:** FlowCRM product/system evidence.

## Cross-page monotony guardrail

A, C and D must have materially different silhouettes. B can share narrative foundations across personal cases but must vary project-media composition based on the actual evidence object and asset ratio.

Fail conditions:
- replacing title/image in one universal hero works for every route;
- every project begins with the same three metric chips and same media rectangle;
- every content chapter is a bordered card grid;
- all project media is forced to one ratio or grayscale treatment.

## Consistency anchors across families

Consistency should come from:
- global navigation behavior;
- type families and semantic scale;
- warm-neutral portfolio chrome;
- hairline/index notation;
- action/focus language;
- caption/meta grammar;
- section rhythm tokens.

Consistency must not come from a universal hero shell.
