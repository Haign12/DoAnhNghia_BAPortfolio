## Final reference A — Pentagram

URL: `https://www.pentagram.com/` / `https://www.pentagram.com/work`
Type: PRODUCTION

What works:
- work is the core information architecture, not a late gallery;
- project discovery is supported by sectors/disciplines/search;
- individual work has strong descriptive titles and visual evidence.

Transferable principle:
- make project proof the site’s dominant object and provide strong information scent.

Do not copy:
- agency-scale filters/categories; this personal portfolio has far fewer projects.

Adaptation:
- 1 curated work index on Home with project type/role/platform and direct case/live pathways.

## Final reference C — PORTO ROCHA

URL: `https://www.portorocha.com/`
Type: PRODUCTION

What works:

## Final reference F — Studio Freight

URL: `https://studiofreight.com/info`
Type: PRODUCTION

What works:

Transferable principle:

Do not copy:

Adaptation:

## Final reference G — Aesop

URL: `https://www.aesop.com/philosophy-on-design.html`
Type: MOOD_REFERENCE

What works for mood:
- restraint, material intelligence, quiet confidence and contextual design.

What it does NOT prove:
- portfolio navigation, hiring conversion, case-study UX.

Adaptation:
- warm paper-like neutrals, disciplined spacing, low-gloss surfaces and careful detail; no literal retail/packaging mimicry.

## Extracted Design DNA

- Layout: editorial asymmetry within a disciplined wide desktop grid; no universal centered card stack.
- Hierarchy: strong serif display moments + highly readable sans body; mono only for sparse metadata.
- Surface: warm neutral/paper field, near-black ink, subtle bronze/earth accent proposed for wayfinding only.
- Media: project assets dominate and retain project-specific color; avoid blanket grayscale.
- Lines/depth: hairline rules and tonal fields; little/no drop-shadow decoration.
- Interaction: quiet reveal/orientation feedback; no motion before content access.
- Conversion: proof → fit → contact, not contact-first.

## Rejected patterns

- Awwwards/gallery-style animation as UX proof.
- Universal cinematic hero video.
- Excessive serif/gold/black “luxury” clichés.
- Frosted glass/pill UI as default.
- One case-study template where only title/image changes.
- 3D/ WebGL dependence unsupported by current assets/performance scope.
