# Visual Signature — Editorial Systems Thinking

Date: 2026-09-04

## Strongest existing cues to preserve/recover

FACT from OLD baseline/source:
- DM Sans structural display;
- Instrument Serif italic contrast;
- DM Mono metadata/index language;
- oversized English positioning statement;
- portrait + geometry composition;
- black/white materiality;
- project-native media.

## Digital signature system

### Typography behavior
- Sans makes the assertion.
- Serif interrupts or reframes the assertion.
- Mono acts as indexing/technical notation.
- Do not flatten all three roles into one family.

### Grid/composition rhythm
- 12-column desktop grid.
- Intentional asymmetry.
- One strong visual object may overlap the grid boundary without harming text legibility.
- Lower sections alternate high/low density rather than repeating identical containers.

### Recurring graphic device
- thin indexed rules + coordinate/folio notation;
- line/circle geometry around portrait or project preview;
- project preview treated as a movable “evidence plate”.

### Image behavior
- original project color;
- curated crop;
- preview max size smaller than previous static 880px stack;
- one primary preview at a time in Work.

### CTA treatment
- black filled primary action;
- underlined secondary text action;
- no rounded pill system as dominant language.

### Motion language
- reveal once;
- project-selection transition;
- subtle portrait/evidence plate parallax only when motion preference allows;
- no continuous decorative loop.

## Generic patterns to avoid

- Inter everywhere;
- centered hero + right image with no authored tension;
- repeated full-width thumbnail/card stacks;
- bento-card soup;
- glass/gradient/3D trend layer;
- oversized decorative type disconnected from work;
- custom cursor as the only interaction cue.

## Recognition test

If logo/header are removed, the portfolio should still be recognizable by at least three independent cues:
1. DM Sans assertion + Instrument Serif interruption;
2. mono index/folio notation;
3. asymmetric evidence-plate/project-preview composition with thin geometry.

## Correct application

- Work explorer uses the same index/mono language as hero.
- Case studies inherit the font roles and quiet rules but keep project-specific visual anchors.
- Contact uses the same mixed type, not a new style.

## Incorrect application

- every section introduces a different font/effect;
- project preview interaction is duplicated everywhere;
- dark mode becomes a separate visual identity;
- project imagery is recolored to match the portfolio chrome.
