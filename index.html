04HOW I WORK

A loop, not a ceremony.

Decide → make → inspect → repair.

The process adapts to the risk. The invariant is that each stage leaves evidence the next stage can challenge.

01 / RESEARCH

Establish truth

Business goal, audience, current-state audit, references, constraints and unknowns.

Gate: enough evidence to frame the problem
02 / UX + IA

Shape the decision path

Top tasks, page roles, journey, sitemap, content priority and edge cases.

Gate: every route has a job
03 / ART DIRECTION

Define a visual thesis

Reference benchmark, visual signature, type, color, media behavior and anti-patterns.

Gate: distinctive and appropriate, not trend collage
04 / SYSTEM

Write the contract

Tokens, components, states, responsive rules, accessibility and behavior contracts.

Gate: decisions are reusable
05 / BUILD

Prototype the real pressure

Responsive implementation exposes content, layout, interaction and state problems.

Gate: source behavior matches intent
06 / QA + REPAIR

Critique the rendered result

Browser screenshots, accessibility, overflow, keyboard, links, Lighthouse and visual critique.

Gate: evidence passes — or loop back
